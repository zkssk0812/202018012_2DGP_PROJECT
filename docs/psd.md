
# 텅 빈 정령 — 기획 문서 (PSD)

> 기술이 하나도 없는 정령이 친구들의 검은 기운을 흡수해 구하며 강해지는 이야기

- 과목: 2D게임프로그래밍(03) 프로젝트
- 작성: 김정호 · 2026년 11월
- 원본: `docs/텅 빈 정령 — 기획서.pptx`
- **수치는 모두 초안이며 플레이테스트로 조정한다. 정령 이름은 가칭이다.**

## 1. 개요

| 항목        | 내용                                |
| ----------- | ----------------------------------- |
| 장르        | 탑다운 2D 액션 RPG                  |
| 플레이 시간 | 한 판 10~15분                       |
| 조작        | 방향키 + Space + QWER + F           |
| 개발        | Python + pico2d, 5주 (11/4 – 12/8) |

**핵심 컨셉:** 쓰러뜨린 적의 검은 기운을 흡수해 그 기술을 내 것으로 만든다.

### 1.1 기획 의도

1. **시스템 = 이야기** — 검은 기운을 흡수하는 행동 하나가 친구를 구하는 일이자 기술을 얻는 방법이다.
2. **약함에서 시작하는 성장** — 기술 0개, 피하는 것밖에 못 하던 정령이 4칸을 채워 대정령과 맞선다.
3. **5주에 완성 가능한 범위** — 디자인 6종, 숲 3개, 엔딩 1개로 처음부터 끝까지 끊기지 않는 한 판.
4. 모든 캐릭터와 설정은 오리지널 창작이라 결과물을 공개 배포할 수 있다.

## 2. 스토리

### 2.1 세계관

소환사들은 숲의 정령과 계약해 힘을 빌려 쓴다. 상처받은 감정이 쌓이면 검은 기운이 된다.

1. 소환사에게 모질게 대해지고 버림받은 정령
2. 슬픔·원망·두려움이 쌓여 검은 기운이 됨
3. 검은 기운에 잠식되어 타락하고 난폭해짐
4. 모아가 흡수하면 부정한 감정은 빠지고 힘의 형태만 기술로 남음

### 2.2 주인공 — 텅 빈 정령 모아 (가칭)

기술이 하나도 없어 소환조차 거부된 정령. 계약의 각인이 없는 텅 빈 몸이라, 다른 정령은 받아들일 수 없는 검은 기운을 흡수할 수 있다. 약해서 거부당한 이유가 그대로 유일한 능력이 된다.

### 2.3 오프닝 · 튜토리얼

친구가 스스로를 쓰러뜨려 모아를 지킨다. 이동 → 회피 → 흡수를 순서대로 배운다.

| 단계           | 내용                                                                            |
| -------------- | ------------------------------------------------------------------------------- |
| 1. 평화로운 숲 | 이동만 가능, 친구 토리와 대화                                                   |
| 2. 토리의 타락 | 검은 기운에 괴로워하다 모아에게 달려듦 → 전투 시작                             |
| 3. 버티기 15초 | 기술이 없어 피하기만 가능 → Space 회피 배움 (남은 시간은 화면에 표시하지 않음) |
| 4. 토리의 선택 | 모아를 다치게 할까 두려워 스스로를 공격해 기절                                  |
| 5. 첫 흡수     | 기절한 토리 주변 검은 기운 안에서 F로 흡수 → 토리는 원래 색으로, Q에 **할퀴기** 획득 |
| 6. 결심        | "이번엔 내가 지킬 차례야" → 숲1로                                              |

- 오프닝 전투는 친구 토리(Lv2)의 공격을 15초 동안 피하는 빈터 전투다.
- 첫 기술은 친구 토리의 기술이다.

### 2.4 숲별 흐름

숲 깊이 갈수록 상처의 흔적이 짙어진다.

| 숲            | 주제          | 내용                                                                                                                                 |
| ------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 숲1           | 처음 나선 길  | 스스로 친구들을 구하러 나선다. 바람의 상위 정령 **실프**가 "더 들어가면 안 돼"라며 막아선다.                                   |
| 숲2           | 짙어지는 상처 | 바위의 상위 정령 **노움**: "그분께 가면 너도 삼켜진다. 약한 네가 갈 곳이 아니야."                                              |
| 숲3 · 보스방 | 분노한 대정령 | 대정령: "소환조차 거부당한 너야말로 인간을 원망해야 하지 않느냐" / 모아: "나는 누구를 원망하려는 게 아니라, 친구들을 지키려는 거야." |

- 상위 정령들은 타락했지만 고위 정령이라 정신을 어느 정도 붙잡고 있어, 위험한 대정령에게 가지 못하도록 모아를 돌려보내려 한다. 정화되면 모아의 각오를 인정하고 대정령을 부탁하며 길을 비켜 준다.
- 구한 정령들이 보스방에 모여 응원한다. 대정령을 정화하면 숲이 되살아나는 **엔딩 1개**.

## 3. 게임 흐름

```
탐험 → 조우 → 전투 → 흡수 → 성장 → (숲 끝) 상위 정령
```

| 단계         | 내용                    |
| ------------ | ----------------------- |
| 1. 탐험      | 숲을 이동, 열매로 회복  |
| 2. 조우      | 수풀 안에서 랜덤        |
| 3. 전투      | 1대1 실시간             |
| 4. 흡수      | 정령을 구하고 기술 획득 |
| 5. 성장      | 레벨업, 칸 해금         |
| 6. 상위 정령 | 숲 끝의 보스            |

숲1 → 숲2에서 반복하고, 숲3 보스방에서 대정령을 정화하면 엔딩.

## 4. 시스템

### 4.1 흡수

| 단계      | 내용                                                               |
| --------- | ------------------------------------------------------------------ |
| 기절      | 적 HP 0 → 죽지 않고 검은 기운이 약해져 잠시 움직이지 못하는 상태  |
| 흡수      | 검은 기운 범위 안에서 **F**를 눌러 흡수. 검은 기운이 빠지고 원래 색으로 돌아와 숲으로 |
| 기술 획득 | 빈칸에 자동 배치, 꽉 차면 버릴 기술 선택 창                        |

**흡수 범위 (F키)**

- 적이 기절하면 그 몸을 중심으로 검은 기운이 **원형 범위**로 퍼진다 (반지름 초안 80px, 바닥에 원으로 표시).
- 모아의 몸 원이 범위 안에 들어가면 머리 위에 `F` 안내가 뜨고, 이때 F를 누르면 흡수가 시작된다.
- 범위 밖에서 F를 누르면 아무 일도 없다. 기절한 적은 흡수될 때까지 그 자리에 남아 있다.
- 판정은 4.5의 원 판정을 그대로 쓴다: 두 중심 사이 거리 ≤ 흡수 범위 반지름 + 몸 반지름.

| 상대      | 획득 규칙                                                         |
| --------- | ----------------------------------------------------------------- |
| 일반 정령 | **30%** 확률로 그 정령의 기술 중 하나를 랜덤 획득           |
| 상위 정령 | 특별 기술 2개 중 1개를 **반드시** 획득 (어느 쪽인지는 랜덤) |
| 공통      | 이미 가진 기술은 나오지 않음 · "버리지 않기"도 선택 가능         |

### 4.2 성장 · 기술 칸

성장 요소는 세 가지뿐: 레벨업 능력치, 레벨에 따라 열리는 기술 칸, 그 칸을 채우는 흡수한 기술.

| 칸 | 해금        | 시점               |
| -- | ----------- | ------------------ |
| Q  | 시작        | 오프닝에서 첫 기술 |
| W  | 시작        | 숲1 첫 흡수로 채움 |
| E  | Lv10        | 실프를 이기는 순간 |
| R  | Lv15 (최대) | 노움을 이기는 순간 |

- 진화나 레벨업으로 배우는 기술은 없다. 모든 기술은 흡수로만 얻는다.
- QWER은 칸일 뿐 정해진 역할이 없다. 잠긴 칸은 자물쇠 아이콘으로 표시한다.

### 4.3 조우 · 패배 · 회복

필드에는 적이 보이지 않고, 수풀 안을 움직이면 확률로 정령을 만난다.

| 숲  | 조우 확률                  |
| --- | -------------------------- |
| 숲1 | 10%                        |
| 숲2 | 12%                        |
| 숲3 | 0% (작은 보스방, 대정령만) |

- 길 위에서는 조우 없음. 조우하면 전투 맵으로 이동, 끝나면 조우한 자리로 복귀.
- **패배:** 조우한 자리에서 HP 절반으로 다시 시작.
- **회복 열매:** 닿으면 최대 HP 30% 회복, 60초 뒤 다시 열림. 숲1 넉넉, 숲2 적게, 숲3 입구 1개.

### 4.4 전투

피하고, 고르고, 반격하는 1대1 실시간 전투.

**조작**

| 키          | 동작                                                         |
| ----------- | ------------------------------------------------------------ |
| 방향키      | 이동 (8방향)                                                 |
| Space       | 회피: 대시, 0.3초 무적, 쿨다운 1.5초 (기술이 아닌 기본 동작) |
| Q W E R     | 흡수한 기술 4칸, 역할 없음                                   |
| F           | 흡수: 기절한 적의 검은 기운 범위 안에서만 동작               |
| Enter / Esc | 대화 / 일시정지                                              |
| T           | 관리자 모드 켜기/끄기 (디버깅용, 4.8 참고)                   |

**규칙**

- 피해 = `위력 × (공격 ÷ 방어) × 0.25`
- 속성·상성 없음
- 피격 시 넉백 + 0.5초 무적, 지속 피해는 계속 들어감
  - 무적은 모아에게만 준다. 정령은 짧게(0.15초) 밀려나고 무적이 없다. 연속 주먹·세 갈래 바람이 모두 맞도록 하기 위함
  - 맞으면 예고 중이던(판정이 아직 안 켜진) 공격은 취소된다
- 한 번 시전에 같은 대상은 1회만 명중
- 적 HP 0 → 기절 → 검은 기운 범위 안에서 F로 흡수 → 숲의 조우한 자리로 복귀
- 내 HP 0 → 그 자리에서 HP 절반으로 재시작

### 4.5 충돌 판정

격자 없이 자유 이동이므로 세 가지 도형으로 판정한다. 정령의 몸은 원 하나 (임시 크기는 5.3 참고). 기술은 바라보는 방향으로 나간다.

| 도형             | 판정 조건                                                                           | 사용처                       |
| ---------------- | ----------------------------------------------------------------------------------- | ---------------------------- |
| 원               | 두 중심 사이 거리 ≤ 두 반지름의 합                                                 | 투사체, 폭발, 주변 범위 기술 |
| 부채꼴           | 거리 ≤ 부채꼴 반지름 + 몸 반지름, **그리고** 방향과의 각도 차 ≤ 각도의 절반 | 근접 기술, 화염방사          |
| 캡슐 (굵은 직선) | 몸 중심에서 가운데 선분까지 거리 ≤ 캡슐 반지름 + 몸 반지름                         | 빔 기술                      |

### 4.6 배틀 AI

전투 안에서만 동작. 위에서부터 확인해 첫 번째로 맞는 기술을 쓴다.

| 우선순위 | 조건                            | 행동                        |
| -------- | ------------------------------- | --------------------------- |
| 1        | HP 30% 이하                     | 방어 기술 또는 회피         |
| 2        | 특별 기술 쿨다운 끝 + 사거리 안 | 특별 기술 (0.5초 예고 동작) |
| 3        | 플레이어와 가깝다               | 근접 기술                   |
| 4        | 그 외 (멀리 있다)               | 원거리 기술                 |

- 없거나 쿨다운 중인 기술은 건너뛴다.
- 기술 사이에 짧은 틈을 둔다.
- 보스도 같은 AI를 쓰고 능력치만 높다.

### 4.7 능력치

HP · 공격 · 방어 세 가지만 쓴다.

- 능력치 = `기본값 × (1 + 0.1 × (레벨 − 1))`, 반올림 (레벨 1마다 기본값의 10%씩 증가)
- 피해 = `위력 × (공격 ÷ 방어) × 0.25`

**모아 (기본값 45 / 12 / 10)**

| 레벨               | HP  | 공격 | 방어 |
| ------------------ | --- | ---- | ---- |
| Lv1                | 45  | 12   | 10   |
| Lv10 · E 칸       | 86  | 23   | 19   |
| Lv15 · R 칸, 최대 | 108 | 29   | 24   |

### 4.8 관리자 모드 (디버깅용)

개발·테스트를 빠르게 하기 위한 모드다. 게임 진행에는 쓰지 않는다.

| 키 | 사용 가능 위치 | 동작 |
| -- | -------------- | ---- |
| T | 언제든 | 관리자 모드 켜기/끄기. 켜져 있는 동안 화면 구석에 `ADMIN` 표시 |
| G | 전투 중 | 상대를 즉사시킨다. HP를 0으로 만들어 바로 기절 상태로 넘긴다 (흡수 흐름은 그대로 테스트 가능) |
| K | 언제든 | 기술 선택 창을 연다. 모든 기술(일반 정령 기술 + 상위 정령 특별 기술) 목록에서 골라 QWER 칸에 넣거나 바꾼다 |

- G·K는 관리자 모드가 켜져 있을 때만 동작한다.
- K 창에서는 잠긴 칸(E·R)에도 기술을 넣을 수 있다. 칸 해금 여부와 상관없이 기술을 시험하기 위함이다.
- K 창이 열려 있는 동안 게임은 일시정지된다.
- K 창 조작: ↑↓ 로 기술을 고르고 Q W E R 로 그 칸에 넣는다. 이미 그 칸에 있는 기술을 다시 누르면 뺀다. 다른 칸에 있던 같은 기술은 옮겨진다. K 나 Esc 로 닫는다.
- 관리자 모드에서는 arena 와 기술 판정 도형을 선으로 그려 판정 범위를 눈으로 확인한다 (5.3). 판정이 켜지기 전(예고)은 연한 노랑, 켜져 있을 때는 주황.
- **U**: 피격 범위(몸 원)를 붉은색으로 표시하고 끈다. 관리자 모드와 따로 켜고 끌 수 있다. 무적이라 지금은 맞지 않을 때는 회색으로 바뀐다.

## 5. 기술

### 5.1 기술 종류

숲2의 기술은 숲1 기술의 강화형이다. 숲2에서 기술을 교체하는 것 자체가 진화를 대신하는 성장이다.

| 종류             | 숲1 기본형                     | 숲2 강화형                      |
| ---------------- | ------------------------------ | ------------------------------- |
| 근접             | 앞쪽 부채꼴 1회                | 길게 돌진하며 베기 (캡슐)       |
| 근접 지속 피해   | 근접으로 맞히면 지속 피해      | 내 주변 원 범위에 지속 피해     |
| 원거리           | 작은 투사체                    | 직선 빔 (캡슐)                  |
| 원거리 지속 피해 | 맞히면 지속 피해를 거는 투사체 | 터지면 범위 안 전부에 지속 피해 |
| 방어 (선택)      | 1초 동안 피해 70% 감소         | 1.5초 동안 피해 80% 감소        |

- 정령은 근접형과 원거리형 두 가지. 방어 기술은 정령에 따라 있을 수도, 없을 수도 있다.
- 지속 피해는 위력 대신 최대 HP 비율로 들어간다.

### 5.2 일반 정령 기술 목록

강한 기술일수록 쿨다운이 길다.

| 기술        | 숲 | 종류               | 도형과 효과                      | 위력 | 쿨다운 | 정령         |
| ----------- | -- | ------------------ | -------------------------------- | ---- | ------ | ------------ |

- **능력치:** Lv18 · 243 / 49 / 41
- **기술:** 두 상위 정령의 특별 기술 4개를 모두 씀 — 세 갈래 바람, 바람 칼날, 연속 주먹, 내려찍기
- 새 기술 없이 앞의 보스 기술을 재사용한다. 원거리와 근접을 오가며 모은 4칸을 시험한다.
- 이기면 기술 대신 엔딩: 대정령이 분노를 내려놓고 숲이 되살아난다.

### 6.6 핵심 재미 — 구할수록 강해진다

1. **빈손에서 시작하는 성장** — 피하기만 하던 오프닝에서 4칸을 채운 최종전까지
2. **무엇을 담고 버릴까** — 한정된 칸, 숲2에서는 강화형으로 교체하는 성장
3. **보스의 힘을 내 것으로** — 길을 막던 상위 정령의 특별 기술을 반드시 흡수
4. **직접 피하고 때리는 손맛** — 예고 동작을 보고 Space로 피한 뒤 반격
5. **구하는 감정선** — 원래 색을 되찾는 정령들, 보스방에 모인 응원
